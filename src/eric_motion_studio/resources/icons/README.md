# UI icons

Place the PNG assets used by the editor in this directory:

- `add_keyframe.png`
- `delete_keyframe.png`
- `move_up.png`
- `move_down.png`
- `duplicate_keyframe.png`
- `reset_joint.png`

Recommended assets are square PNGs (24–32 px). The UI shows a text fallback until
the corresponding PNG is added.
