# Pose Library backup

`pre-change-source-dc7c77c.tar.gz` contains the baseline versions of every
tracked file changed by the searchable Pose Library implementation.

Baseline commit:

```text
dc7c77c42235be0d622ecba7de62d8ae818d0b7b
```

The Pose Library service, widget, built-in metadata catalog, schema, tests, and
documentation are new files and therefore have no pre-change archive member.

List the archive without extracting:

```bash
tar -tzf backups/pose-library/pre-change-source-dc7c77c.tar.gz
```
